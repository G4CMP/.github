# .github

This repository contains the public organization profile in the file profile/README.md.

Only the main branch profile/README.md is displayed on the organization's landing page https://github.com/G4CMP. The develop branch can be used to check if the markdown formatting is correct before merging changes to the main branch. You can also edit the profile/README.md directly in your browser and use GitHub's preview, if you don't have a markdown previewer.
