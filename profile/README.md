The G4CMP developer's consortium contributes to the development of new features in G4CMP and related packages with the general goal to model low energy physics processes in cryogenic devices.

The [G4CMP confluence space](https://confluence.slac.stanford.edu/spaces/G4CMP/pages/479598562/G4CMP+GEANT+for+Condensed+Matter+Physics) provides documentation of the packages and instructions for how to join the G4CMP developer's consortium.
